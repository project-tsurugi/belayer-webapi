* add `systemd/register_service.sh`, which registers Belayer and the TsurugiDB as systemd services. The TsurugiDB runs in a unit of its own (`tsurugidb-<name>.service`), and Belayer starts it with `sudo systemctl start` of that unit; a sudoers entry lets the user run that command, and nothing else, without a password. `--with-auth-server` also registers the authentication server (harinoki), `--tsurugidb-only` the TsurugiDB alone. `systemd/unregister_service.sh` removes them.
* add `--tsurugi-home`, `--tsurugi-conf`, `--storage`, `--port` and `--management-port` to `install.sh`. It writes `TSURUGI_URL` from `[ipc_endpoint] database_name` of the configuration of the TsurugiDB. For several TsurugiDBs on one node, install one Belayer for each as its user, with other ports and another service name (`--name`).
* set `TSURUGI_TGCTL_COMMAND` to `bin/tgctl_dispatch.sh`, which decides how the TsurugiDB is started and passes everything else on to `tgctl_w` (`BELAYER_TGCTL_DELEGATE`). Without systemd, it starts the TsurugiDB in a session and process group of its own.
